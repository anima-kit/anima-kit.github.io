# :material-dna:{ .icon-def-0 } About

<hr class="icon-def-1", style="border-top: 0.2rem dotted; border-bottom: transparent; width: 90%; margin: 0 auto;"> 

!!! tl-dr "TL;DR"
    I like building AI projects and I want to learn more and contribute to the field :material-robot-excited-outline:{ .icon-def-0 }. So, I'm distilling what I've been learning and packaging it for anyone that wants to learn with me :material-wizard-hat:{ .icon-def-0 }.

## :material-robot-love-outline:{ .icon-def-0 } What's anima-kit about?    

When I realized that I wanted to be a part of the AI field, I didn't really know anyone that was in it :material-head-dots-horizontal-outline:{ .icon-def-0 } and my biggest assets in learning were online tutorials :material-search-web:{ .icon-def-0 } :material-bookshelf:{ .icon-def-0 }. Before that, I had been working to get my PhD in physics for the past several years and I was almost done with my thesis :material-school-outline:{ .icon-def-0 }. I worked mostly on theoretical models of dark matter :material-telescope:{ .icon-def-0 } :material-ghost-outline:{ .icon-def-0 } which required nothing but something to write with :material-pencil-outline:{ .icon-def-0 }, something to write on :material-note-outline:{ .icon-def-0 }, and stamina :material-run:{ .icon-def-0 }. Almost all calculations could be done without any help from a computer, which is to say, almost all functions of the theories I worked on could be solved exactly :material-equal:{ .icon-def-0 }. 

However, there *were* some numerical calculations that could be done :material-desktop-classic:{ .icon-def-0 }, specifically in regards to how certain theoretical, cosmological clouds form :material-cloud-question-outline:{ .icon-def-0 }. With respect to this, the idea of a reinforcement learning project got floated around and even though it didn't pan out, it marked the beginning of my gravitation towards learning AI and towards learning how to create code in general :material-file-code-outline:{ .icon-def-0 }. 

!!! memory-bubble "Memory"

    *Training an agent in a custom environment using the [A2C][a2c]{.blank} method with [Stable Baselines 3][stable-baselines]{.blank}*

Ah, very fond memories of these times :material-heart-outline:{ .icon-def-0 }. It was one of the first that I had taken other people's code and tried to create something new with it :material-creation-outline:{ .icon-def-0 }. I was starting to see how I could build some really cool things if I started to embrace this field. I wanted to get my hands dirty :material-hammer-wrench:{ .icon-def-0 } and build something that I could use in my everyday life :material-account-hard-hat-outline:{ .icon-def-0 }. The shock of AI, its sheer practicality and the promise of hours of entertainment struggling through debugs :material-bug-outline:{ .icon-def-0 }, was so much that I haven't been able to take my eyes off it since :material-head-heart-outline:{ .icon-def-0 }.

---

Around this time, I started to notice that generative AI :material-generator-portable:{ .icon-def-0 } had been popping up through open source models and libraries. I began playing around with [an early precursor][sd-early]{.blank} to the :material-image-multiple-outline:{ .icon-def-0 } [Stable Diffusion][stability-ai]{.blank} models using :simple-huggingface:{ .icon-def-0 } [Huggingface Diffusers][diffusers]{.blank}. I didn't have a viable :material-expansion-card-variant:{ .icon-def-0 } GPU at the time so I was paying for Google GPUs, going through every tutorial I could find :material-bookshelf:{ .icon-def-0 }. There was a community of people that were sharing their work, explaining how to use image generation models and how they worked :material-gift-outline:{ .icon-def-0 }. 

I learned how to [fine-tune][fine-tune]{.blank} text-to-image models, how to create [LoRAs][lora]{.blank}, and how to generate images through different pipelines :material-pipe:{ .icon-def-0 } for different outcomes :material-shape-plus:{ .icon-def-0 }. I was burning up Google resources using [kohya-ss's SD scripts][sd-scripts]{.blank} and [automatic1111's SD web UI][sd-webui]{.blank} (a pioneer for one of my favorite tools, [ComfyUI][comfyui]{.blank}). It was fun, but something was still missing :material-head-question-outline:{ .icon-def-0 }. I felt as though this was only a hobby for me, there was something else I was trying to aim for :material-bow-arrow:{ .icon-def-0 }.  

I was sure of one thing, though. I *really* wanted a GPU with lots of [VRAM][vram]{.blank} :material-head-heart-outline:{ .icon-def-0 }.

Soon after, I started to play around with [text-generation models][models-text-gen]{.blank} (i.e. the designation for most LMs [^multi-modal]) and I began to notice the existence of AI agent frameworks that utilized these models to power agents, such as [ChatDev][chatdev]{.blank} and [AutoGen][autogen]{.blank}. At the time, I could do some of the quickstart tutorials for these repos :material-checkbox-marked-outline:{ .icon-def-0 }, but I couldn't get my agents to do anything very useful for me :material-robot-confused-outline:{ .icon-def-0 }. It seemed they were either still in the early stages or I didn't understand how to use them. Either way, I felt something immense was on the precipice :material-volcano-outline:{ .icon-def-0 } and I wanted to join in :material-crowd:{ .icon-def-0 } and learn more :material-robot-excited-outline:{ .icon-def-0 }.

!!! memory-bubble "Memory"
    *Scratch that. Life's throwing you something that requires your utmost presence and emotional stability. Better find your lodestone and better find it quick.*

Nothing quite like difficult life experiences to strengthen one's resolve, endurance, and faith in oneself :material-weight-lifter:{ .icon-def-0 }. Throughout this experience, I couldn't dedicate very much time to the field and I started to lose touch :material-head-question-outline:{ .icon-def-0 }. But, when I was able to put my feet back down on solid ground :material-sprout-outline:{ .icon-def-0 } and come back to my learning, I found that AI agent frameworks had become quite good and that [LangChain][langchain]{.blank} and [LangGraph][langgraph]{.blank} were the marks in my sight :material-bullseye-arrow:{ .icon-def-0 }. I could easily make the agents that I had been wanting to make since I realized frameworks like this existed :material-robot-love-outline:{ .icon-def-0 }. 

I sure did find my lodestone during this time :material-magnet-on:{ .icon-def-0 } :material-compass-outline:{ .icon-def-0 } and trying to contribute to the field of AI is a part of it. So, [let's go][tutorials]! :material-rocket-launch-outline:{ .icon-def-0 }   

<hr class="icon-def-1", style="border-top: 0.2rem dotted; border-bottom: transparent; width: 60%; margin: 0 auto;"> 

## :material-flask-round-bottom:{ .icon-def-0 } Why these tutorials?

I'm not a developer (yet) :material-flag-triangle:{ .icon-def-0 }. I didn't learn how to code in an organized, systematic way like in a classroom :material-school-outline:{ .icon-def-0 }. I taught myself how through wanting to build things :material-robot-outline:{ .icon-def-0 }, then searching the internet (or chatting with LMs) for solutions :material-magnify:{ .icon-def-0 }. 

When I first started learning how to code and how to use AI :material-sprout-outline:{ .icon-def-0 }, it felt like starting to learn physics all over again. It's pretty difficult to understand what's going on when everyone uses words that you've never heard :material-head-question-outline:{ .icon-def-0 }, and I'm all too familiar with how it feels to try to join a field that you're completely alien to :material-alien-outline:{ .icon-def-0 } :material-ufo-outline:{ .icon-def-0 }. 

First, it can be difficult to find good teachers :material-map-marker-question-outline:{.icon-def-0}. Lots of people don't care to or they don't understand the material well enough :material-head-question-outline:{ .icon-def-0 }. I've had plenty of teachers that left me so confused and showed so little motivation to clarify that I felt I might as well learn on my own :material-head-remove-outline:{ .icon-def-0 }.  

To top off the mounting difficulties of learning a new field and trying to find good teachers :material-image-filter-hdr-outline:{ .icon-def-0 }, the field of AI is so vast and moves so ridiculously fast :material-rocket-launch-outline:{ .icon-def-0 }. There's always a new app, or repo, or technique and everyone's using something different :material-shape-plus:{ .icon-def-0 }. At some point, I almost gave up on trying to join the field because it's so daunting :material-emoticon-dead-outline:{ .icon-def-0 }. I felt like, how could I ever actually keep up?

But, what helped me (and still helps me) is trying to take it all one step at a time :material-stairs:{.icon-def-0}, one unknown word :material-puzzle-outline:{ .icon-def-0 }, one bug :material-bug-outline:{.icon-def-0}, one demo :material-laptop:{.icon-def-0} at a time. As I started to learn more, I found that feelings of incapability couldn't keep me away. It's too fun, it's too useful. The thrill in learning and building something is too powerful :material-volcano-outline:{ .icon-def-0 }.

It also helps that I've learned a thing or two about *how to learn* from the few teachers that took the time to not only try to teach the subject material, but how to learn it :material-creation-outline:{ .icon-def-0 }. These have been quite rare :material-clover-outline:{ .icon-def-0 } but are greatly appreciated. Notice how these rare souls tend to have strong compulsions to grow along with impressive emotional intelligences to boot? They inspire me to follow in their footsteps :material-hiking:{ .icon-def-0 }. I'm not sure that I'm a very good teacher for this subject material yet. But I do love it :material-heart-outline:{ .icon-def-0 } and the more I teach others, the more I distill my own knowledge :material-flask-round-bottom:{ .icon-def-0 }. 

---

Now, my learning technique for this subject material has been to figure out how to build something :material-magnify:{ .icon-def-0 }, get it to work :material-hammer-wrench:{ .icon-def-0 }, then dive into the code to understand it better :material-diving-scuba:{ .icon-def-0 }. I've learned a lot this way, by trying to understand and build on other people's code, and now I understand enough to make my own specialized agents :material-robot-happy-outline:{ .icon-def-0 } :material-wizard-hat:{ .icon-def-0 }. 

But, when I started cleaning all the projects that I had accumulated over my course of learning :material-monitor-shimmer:{ .icon-def-0 }, I realized how confused *I still was* :material-head-question-outline:{ .icon-def-0 }. So, I started making tutorials with an audience of non-experts in mind :material-crowd:{ .icon-def-0 }. Because that's what I am, a non-expert trying to learn the field :material-puzzle-outline:{ .icon-def-0 }, and it was *definitely* what I was when I started learning and needed the tutorials of others to get a jump start :material-hand-heart:{ .icon-def-0 }.

## :material-gift-open-outline:{ .icon-def-0 } What are the tutorials like?

I've structured my tutorials similarly to the way that I originally learned the material. Show how to get something to work :material-monitor-shimmer:{ .icon-def-0 }, then show why it does :material-file-code-outline:{ .icon-def-0 }. This way, if anyone wants to just take the code and get it working without learning anything about it :material-invoice-text-fast-outline:{ .icon-def-0 }, they can. Whoever wants to dive into how the code works afterwards can then follow along with the rest of the tutorial :material-book-open-variant-outline:{ .icon-def-0 }. 

The first part of each tutorial is then dedicated to step-by-step guides to get the code working in various situations :material-stairs:{ .icon-def-0 }. These are followed by deep dives into the code :material-diving-scuba:{ .icon-def-0 } where we break apart the most imperative parts :material-chart-pie-outline:{ .icon-def-0 } and learn how they work. There are also optional dives that I found to not be *strictly necessary* for understanding, but that I kept for those that want all that knowledge :material-wizard-hat:{ .icon-def-0 }.

It's probably pretty obvious by now that I like to use code that I can open up to check out the gears if I need to :material-cog-outline:{ .icon-def-0 }. So, much of the code that we'll use from other libraries will be available to view in all their full glory on :simple-github:{ .icon-def-0 } [Github][github]{.blank}. I also like to use libraries and platforms that are free to use :material-currency-usd-off:{ .icon-def-0 }. No need for a paywall. Just plug into your code and play :material-controller-classic-outline:{ .icon-def-0 }.

---

I originally set out to create these tutorials so that I would better understand the subject material :material-head-sync-outline:{ .icon-def-0 } and gain the necessary skills to create clean and easily digestible, yet highly complex, AI projects :material-robot-love-outline:{ .icon-def-0 }. But, through teaching myself I now feel as though I could teach others :material-bookshelf:{ .icon-def-0 }. 

These projects :material-file-code-outline:{ .icon-def-0 }, these tutorials :material-bookshelf:{ .icon-def-0 }, are proof that someone with very limited knowledge of AI and coding can learn the field enough to build something for themselves and others :material-robot-excited-outline:{ .icon-def-0 }. It seems that it's never been easier for any given human to learn any given subject than it is in our day and age :material-wizard-hat:{ .icon-def-0 }. A ridiculous amount of information is at our fingertips in a moment's notice :material-flash:{ .icon-def-0 }. To distill it into something useful :material-flask-round-bottom:{ .icon-def-0 }, we just need motivation, enduring effort, patience, and proper aim :material-bullseye-arrow:{ .icon-def-0 }.

So, if you want [code to build specialized AI agents][animakit] :material-file-code-outline:{ .icon-def-0 }, or if you want to learn [how the code for building agents works][agents] :material-wizard-hat:{ .icon-def-0 }, or you want [something somewhere in between][tutorials] :material-head-cog-outline:{ .icon-def-0 }, here's my knowledge! :material-hand-heart:{ .icon-def-0 }
