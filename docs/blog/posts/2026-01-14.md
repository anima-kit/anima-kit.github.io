# Creating a template for simple web apps using Go and Next

I've been learning how to create web apps with [Go][go], [gqlgen][gqlgen], and [Next][next], and I wanted to create a step-by-step guide outlining how to build a reusable scaffold. As I learned more, I felt compelled to distill my learning in order to better understand the logic that goes into creating more complex apps. So, of course I [made a tutorial][tutorial]{data-preview}! :material-monitor-shimmer:{ .icon-def-0 }
<!-- more -->

In this tutorial, I go over each of the steps necessary for creating a reusable web app template using Go on the backend and Next on the frontend. I then show how to define and use custom schemas using gqlgen to create [GraphQL][graphql] APIs that can be requested by the frontend. Finally, I show how to add frontend components and connect it all through an [Apollo][apollo] client. 

Soon, I'll add some tutorials outlining some more complex logic, including how to do persist our data with a [Postgres][postgres] DB, so stay tuned! :material-tune-vertical:{.md-icon} You can also check out some of my other [in-depth tutorials][tutorials] covering various aspects of AI :material-bookshelf:{.md-icon}.
